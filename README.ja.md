<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/Assets/Car%20Studio.png" width="35"/> Car Studio</h1>

<p align="center">
  Car Studioは、スキャンした車の画像を詳細な3Dモデルに変換し、没入感のある環境で車両を探索できるインタラクティブな3Dプラットフォームです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/features.gif" width="35"/> 機能

| 機能 | 説明 |
| --- | --- |
| 🎨 **車体カラーの変更** | 好みに合わせて車のカラーを変更し、外観をカスタマイズできます |
| 🔊 **インタラクティブなホーン** | 車のホーンを鳴らして、よりリアルな体験を楽しめます |
| ℹ️ **車両情報** | 車両の詳細情報やスペックを確認できます |
| 🔄 **回転＆探索** | 3D車両モデルを回転させ、さまざまな角度から確認できます |
| 🛞 **インタラクティブなホイール** | 詳細な3Dビジュアライゼーションで車のホイールを確認できます |

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/car-studio.git
````

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd car-studio
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**car-studio**フォルダを指定します。

### 4️⃣ プロジェクトを開く

- Unityによるプロジェクトファイルのインポートが完了したら、**Assets**フォルダからメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押してCar Studioを起動します。

<img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

### 1️⃣ 画像をダウンロード

- リポジトリの`markers`フォルダから**車の画像をダウンロード**して、お使いのデバイスに保存します。

### 2️⃣ アプリをダウンロード

- リポジトリに記載されているリンクから**アプリをダウンロード**します。

### 3️⃣ アプリを起動

- **アプリを開いて**、没入感のあるAR体験を開始します。

### 4️⃣ 画像をスキャン

- **ダウンロードした車の画像をスキャン**すると、3D車両モデルが起動します。

### 5️⃣ ARで車を体験

- **車を没入感のある3Dで表示**し、AR環境でインタラクティブに操作できます。
