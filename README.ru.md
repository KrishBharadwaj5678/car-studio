<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/Assets/Car%20Studio.png" width="35"/> Car Studio</h1>

<p align="center">

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/car-studio.git
````

### 2️⃣ Переход в папку проекта

```bash
cd car-studio
```

### 3️⃣ Добавление проекта в Unity Hub

- Откройте **Unity Hub**, выберите **Add** и укажите клонированную папку **car-studio**

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Car Studio

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

### 1️⃣ Загрузка изображений

- **Скачайте изображения автомобилей** из папки `markers` в репозитории на своё устройство.

### 2️⃣ Загрузка приложения

- **Скачайте приложение**, используя ссылку, указанную в репозитории.

### 3️⃣ Запуск приложения

- **Откройте приложение**, чтобы начать работу с иммерсивным опытом дополненной реальности.

### 4️⃣ Сканирование изображения

- **Отсканируйте любое загруженное изображение автомобиля** с помощью приложения, чтобы активировать 3D-модель.

### 5️⃣ Взаимодействие с автомобилем в AR

- **Просматривайте автомобиль в иммерсивном 3D** и взаимодействуйте с ним в дополненной реальности.
