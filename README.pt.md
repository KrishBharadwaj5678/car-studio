<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/Assets/Car%20Studio.png" width="35"/> Car Studio</h1>

<p align="center">
  O Car Studio é uma plataforma 3D interativa que transforma imagens digitalizadas de carros em modelos 3D detalhados, permitindo que os utilizadores explorem veículos numa experiência imersiva.
</p>

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/car-studio.git
````

### 2️⃣ Aceder à Pasta do Projeto

```bash
cd car-studio
```

### 3️⃣ Adicionar ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta **car-studio** clonada.

### 4️⃣ Abrir o Projeto

- Depois de o Unity terminar de importar os ficheiros do projeto, abra a cena principal a partir da pasta **Assets**.

### 5️⃣ Executar o Projeto

- Prima o botão **Play** no Unity Editor para iniciar o Car Studio.

<img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/divider.gif" width="100%"/> 

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

### 1️⃣ Transferir as Imagens

- **Transfira as imagens dos carros** da pasta `markers` do repositório para o seu dispositivo.

### 2️⃣ Transferir a Aplicação

- **Transfira a aplicação** através do link disponibilizado no repositório.

### 3️⃣ Iniciar a Aplicação

- **Abra a aplicação** para começar a experiência imersiva de realidade aumentada.

### 4️⃣ Digitalizar a Imagem

- **Digitalize qualquer imagem de carro transferida** utilizando a aplicação para ativar o modelo 3D.

### 5️⃣ Explorar o Carro em AR

- **Visualize o carro em 3D de forma imersiva** e interaja com ele através da realidade aumentada.
