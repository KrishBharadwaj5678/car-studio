<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/Assets/Car%20Studio.png" width="35"/> Car Studio</h1>

<p align="center">
  Car Studio is an interactive 3D platform that transforms scanned car images into detailed 3D models, allowing users to explore vehicles in an immersive experience.
</p>

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/features.gif" width="35"/> Features

| Feature | Description |
| --- | --- |
| 🎨 **Change Car Color** | Customize the vehicle by changing its color to your preferred style |
| 🔊 **Interactive Horn** | Activate the car horn for an immersive experience |
| ℹ️ **Car Information** | View detailed information and specifications about the vehicle |
| 🔄 **Rotate & Explore** | Rotate the 3D car model and view it from different angles |
| 🛞 **Interactive Wheels** | Explore and inspect the car’s wheels with detailed 3D visualization |

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/car-studio.git
```

### 2️⃣ Navigate to the Project

```bash
cd car-studio
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **car-studio** folder

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Car Studio

## <img src="https://github.com/KrishBharadwaj5678/car-studio/raw/main/readme/gifs/howItWorks.gif" width="35"/> How It Works 

### 1️⃣ Download the Images

- **Download the car images** from the repository's `markers` folder to your device.

### 2️⃣ Download the App

- [Download the app](https://drive.google.com/file/d/1t7xQ3ww4-yKR6QWagyyC_JvVaKOke_Io/view) using the link provided in the repository.

### 3️⃣ Launch the App

- **Open the app** to begin the immersive augmented reality experience.

### 4️⃣ Scan the Image

- **Scan any downloaded image** using the app to activate the AR experience.

### 5️⃣ Experience in AR

- **View the car in immersive 3D** and experience it through augmented reality.
